# Nexus Web Prototype

**Presence over Noise**

Early web prototype of Nexus — an intentional communication product that breaks the habits of infinite feeds, dopamine loops and platform ownership of your social graph.

## Design principles in this build

- No infinite feed
- Circles of trust instead of public profiles
- Explicit attention states
- Contexts instead of chats-as-default
- Ephemeral by default
- Calm, dark, focused UI inspired by modern messaging references

## Run locally

Just open `index.html` or:

```bash
npx serve .
```
